Write a thread-safe, memory-bounded asynchronous batch processor in Rust (or Go). The processor must accept items from multiple producer tasks, aggregate them into batches of size $N$ or flush them after a timeout of $T$ milliseconds, whichever comes first. It must handle backpressure gracefully by blocking producers when the internal buffer queue reaches a maximum capacity $C$. Ensure that when the processor is explicitly shut down, all remaining items in the buffer are flushed completely before the worker tasks terminate, preventing any data loss.
